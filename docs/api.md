# API проекта (опционально)

На данный момент API **не реализован**, но архитектура позволяет добавить его в будущем.

## Планируемые эндпоинты

### Каталог

- `GET /api/products/` – список товаров (с фильтрацией, пагинацией)
- `GET /api/products/{id}/` – детальная информация о товаре
- `GET /api/categories/` – список категорий
- `GET /api/brands/` – список брендов

### Избранное

- `GET /api/wishlist/` – список избранных товаров пользователя
- `POST /api/wishlist/add/` – добавить товар в избранное
- `POST /api/wishlist/remove/` – удалить товар из избранного

### Отзывы

- `GET /api/reviews/?product_id={id}` – список отзывов по товару
- `POST /api/reviews/` – добавить отзыв
- `POST /api/reviews/{id}/reply/` – ответ администрации

### Аутентификация

- `POST /api/auth/login/`
- `POST /api/auth/logout/`
- `POST /api/auth/register/`

---

## Формат данных

API будет использовать **JSON** с единым форматом ответа:

```json
{
  "status": "success",
  "data": { ... },
  "message": "Описание результата"
}
```

---

## Технологии

- Django REST Framework (DRF) – планируемый фреймворк
- JWT или сессионная аутентификация (на выбор)
- Документация через drf-yasg или Swagger

---

## Статус

**В разработке** – планируется в рамках долгосрочного развития.
