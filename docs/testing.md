# Тестирование проекта

## Запуск тестов

Все тесты находятся в приложении `products`.

```bash
python manage.py test apps.products
```

---

## Структура тестов

```
apps/products/tests/
├── __init__.py
├── test_models.py          # Тесты моделей (Product, Category, Brand)
├── test_views.py           # Тесты представлений (каталог, страница товара, поиск)
└── test_services.py        # Тесты сервисов (похожие товары)
```

---

## Что проверяется

### Модели

- Создание товара с обязательными полями.
- Генерация `get_absolute_url()`.
- Корректность `__str__()`.

### Представления

- Доступность страницы каталога (статус 200).
- Отображение товаров на странице каталога.
- Доступность страницы товара (статус 200).
- Отображение названия товара на его странице.
- Поиск (регистронезависимый).

### Сервисы

- Поиск похожих товаров возвращает как минимум один товар.
- Список похожих товаров не содержит сам товар.

## Настройка тестовой среды

Для тестов используется отдельная база данных (создаётся автоматически). Настройки статики переопределены для избежания ошибок с `ManifestStaticFilesStorage`.

```python
# config/settings/test.py
from .base import *

STATICFILES_STORAGE = "django.contrib.staticfiles.storage.StaticFilesStorage"
```

---

## Расширение тестов

При добавлении новых функций рекомендуется писать тесты для:

- Моделей (`Review`, `ReviewReply`, `ReviewImage`)
- Представлений (добавление отзыва, лайтбокс)
- Сервисов (обновление рейтинга)
