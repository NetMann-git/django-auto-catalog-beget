## 🚀 Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/NetMann-git/django-catalog.git
cd django-catalog

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
source .venv/bin/activate      # Linux/macOS
.venv\Scripts\activate         # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать .env
# SECRET_KEY=...
# DEBUG=True
# ALLOWED_HOSTS=127.0.0.1,localhost

# 5. Выполнить миграции
python manage.py migrate

# 6. Собрать статику
python manage.py collectstatic --noinput

# 7. Запустить сервер
python manage.py runserver
```

## 🧩 Основной функционал

### 📦 Товары
- Универсальная модель `Product`
- Категории, бренды, бейджи
- Галерея изображений
- Универсальные характеристики (`AttributeType` + `AttributeValue`)
- SEO-поля (`meta_title`, `meta_description`)
- Статусы наличия (в наличии, под заказ, последний размер, нет в наличии)

### 🔍 Фильтрация и поиск
- Фильтры: категория, бренд, силуэт, коллекция, цвет, цена, наличие
- Поиск по названию, артикулу, описанию
- Сортировка и пагинация

### ❤️ Избранное
- Для авторизованных (БД) и гостей (сессия)
- AJAX-добавление/удаление
- Счётчик в шапке

### ⚖️ Сравнение товаров
- До 4 товаров
- AJAX-управление
- Таблица характеристик

### 👁️ Недавно просмотренные
- Хранение в сессии
- Блок на странице товара
- Отдельная страница

### 💬 Отзывы
- Оценка 1–5 звёзд
- Фото в отзывах
- Голосование (полезно/не полезно)
- Фильтрация и сортировка

### 📐 Размерный помощник
- Подбор размера по параметрам
- Таблица размеров

### 👤 Пользовательская система
- Регистрация, вход, выход
- Восстановление пароля
- Личный кабинет
- Панель продавца
- Панель менеджера
