# Архитектура проекта

## Общая концепция

Проект построен на принципе **чистой архитектуры** с разделением на слои:

- **Модели** (models) — описание данных.
- **Репозиторий** (Repository) — слой доступа к данным.
- **Сервисы** (Service) — бизнес-логика.
- **Фильтры** (Filter) — параметры фильтрации.
- **Пагинатор** (Paginator) — управление постраничным выводом.
- **Контекст-билдер** (ContextBuilder) — подготовка данных для шаблонов.
- **Представления** (Views) — обработка запросов и рендеринг.

---

## Структура приложения `products`

Это основное приложение, отвечающее за каталог.

### Слои (в порядке вызова)

1. **Представление** (`views.py`) — принимает запрос, вызывает `ContextBuilder`.
2. **ContextBuilder** (`context.py`) — собирает контекст, используя `Repository`, `Filter`, `Paginator`.
3. **Repository** (`repository.py`) — получает данные через `QuerySet` и кэширует их.
4. **QuerySet** (`querysets/catalog.py`) — строит SQL-запросы.
5. **Filter** (`filters.py`) — применяет фильтры и сортировку.
6. **Paginator** (`pagination.py`) — пагинация.
7. **Service** (`services.py`) — бизнес-логика (похожие товары, избранное и т.д.).

---

## Взаимодействие с другими приложениями

- **wishlist** — избранное (сессия + БД).
- **reviews** — отзывы и рейтинг.
- **home** — главная страница.
- **search** — поисковая страница.

## Управление товарами (для менеджера)

Менеджер (`role='manager'`) может управлять товарами через интерфейс, без доступа к Django Admin:

- **Список товаров** — `/catalog/manage/`
- **Создание товара** — `/catalog/create/`
- **Редактирование товара** — `/catalog/edit/<id>/`
- **Удаление товара** — `/catalog/delete/<id>/`
- **Управление галереей** — добавление/удаление фото
- **Управление характеристиками** — выбор типа → подгрузка значений
- **Управление бейджами** — чекбоксы с множественным выбором

---

## Кэширование

- Низкоуровневый кэш `CatalogRepository.catalog()` и `filters()`.
- Кэш похожих товаров в `ProductService`.
- Автоматическая очистка кэша через сигналы при сохранении/удалении товара.

---

## Административные интерфейсы

- **Django Admin** (`/django-admin/`) — управление товарами, категориями, брендами, отзывами.

---

## Настройки

- **base.py** — общие настройки.
- **dev.py** — разработка (DEBUG=True, локальный кэш).
- **prod.py** — продакшен (DEBUG=False, безопасность, manifest-статика).
- Переменные окружения через `.env` и `python-decouple`.

---

## Развёртывание

- Сервер: Ubuntu + Gunicorn + Nginx.
- Статика: collectstatic + Nginx.
- Медиа: Nginx.
